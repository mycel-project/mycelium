Mycelium is an open-source learning application built around [Mycel](https://github.com/mycel-project/mycel). 
Mycelium is currently available on Windows, Linux, Android and as a web app. MacOS and iOS support is coming soon. 

See more intormations at [Mycel Project's website](https://mycel-project.com/).
